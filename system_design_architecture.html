1

Presentation Layer

  • Tech Stack: React.js, Next.js (App Router), TailwindCSS, Leaflet.js / Mapbox GL.
  • Fisherman Ingestion: GSM USSD codes (*120# dialers) and standard SMS.
  • Connections: Maps render real-time raster tile overlays (SST/Chlorophyll grids) and draw GeoJSON vector tracks.
2

Integration & Translation Gateway

  • Tech Stack: FastAPI (Python), Uvicorn (ASGI server).
  • Linguistic translation: Uses the Bhashini translation API to translate typed regional text (Tamil, Telugu, Gujarati, etc.) into English text for agents, and translates agent outputs back to the regional language text.
  • GSM Telemetry Gateway: Decodes compressed GSM location tokens.
3

Orchestrator & Safety Engine

  • Orchestrator: LangGraph Planner Node which extracts intent and dynamically calls only the required agents/tools.
  • Specialized Nodes:
    • Weather Agent/Tool: Fetches swell height and wind vectors, attaching data provenance metadata.
    • Ocean Agent/Tool: Computes Chlorophyll & SST gradient fronts (uses synthetic fallback if live APIs fail).
    • Geofence Node: Deterministic polygon checkers for IMBL and MPAs.
    • Safety Assessment Engine: A deterministic Python rules engine that assigns safety risk levels (SAFE/WARNING/CRITICAL).
    • Routing Engine: Runs safe weather path routing (A*) only when alternative actions are required.
    • Consensus Explainer: An LLM generator that translates structured risk levels and conflict logs into user-friendly regional explanations.
4

Data & Analytics Layer

  • Primary Database: PostgreSQL with PostGIS spatial extensions. Stores boundary polygons (IMBL, MPAs) and vessel digital twin histories.
  • Task Broker & Cache: Redis acts as the broker for Celery worker queues and caches processed oceanographic grids.
  • Simulator: NumPy/SciPy ocean noise simulator for offline development testing.

⚡ Core System Optimizations

  • Spatial Indexing (GiST Index): A PostGIS spatial index speeds up vessel-to-geofence overlap calculations from $O(N)$ scanning to logarithmic spatial tree lookups.
  • SST/Chlorophyll Grid Caching: Processed satellite arrays are split into small geographic tiles and cached in Redis, avoiding reloading heavy raw files.
  • Base64 Telemetry Compression: Compresses raw GPS floats into a compact 12-character token, fitting comprehensive tracking updates within a single SMS.
